# System Report

This script displays basic information about the current Linux system for quick inspection.

## Commands Used

### `hostname`

Displays the hostname of the current computer.

### `cat /etc/os-release`

Displays operating system information such as distribution name and version.

### `uname -r`

Displays the current Linux kernel version.

### `lscpu | grep "Model name"`

Displays the CPU model.

### `free -h`

Displays memory usage in a human-readable format.

### `df -h`

Displays disk usage for all mounted filesystems.

### `uptime`

Displays how long the system has been running and the current system load.
